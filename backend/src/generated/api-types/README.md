# Generated OpenAPI boundary metadata

Generated policy metadata and the normalized validation document are derived from `../../../../docs/backend-contracts/openapi.yaml` by `npm run openapi:generate`. This directory is reserved for future transport-only generated types once a TypeScript 7-compatible stable generator is available.

- Do not edit generated files by hand.
- These types belong only at the HTTP transport boundary.
- They are not domain entities and are not Prisma models.
- `npm run openapi:check` fails when committed output differs from the authoritative contract.
