## 2026-09-12 历史补卡、长期档案和凭证补充规则

- 学院、专业、出生日期、地域随平台学生档案保存。已填字段随本人登录后的再次入班自动带入；已验证邮箱不重复绑定，匿名提交学号不允许接管已验证账号。
- 责任教师为当前学期课程独立启用历史补卡并设置最早/最晚日期，允许范围包含入班前日期，但不得越出当前学期。学生只能声明已经完成的过去运动；今天、未来及越界日期被拒绝。声明时保存教师范围版本，后续配置改变不倒改已有声明。
- 历史补卡仅在正常运行、课程有效、学生在课、未结算且常规截止前创建和首次提交。已进入审核的记录保留历史；获准补证沿用既有补证窗口。历史运动是学生申报事实，始终标记“历史补录”，不冒充服务器实时计时；单次声明不超过一天，结束日期也必须早于今天。
- 历史补卡支持选择本机照片/视频，必须有凭证并由责任教师人工审核（包括游泳历史补卡）；不套用实时游泳前后批次的 15 分钟首次上传规则。实际运动时长须满足课程最低时长，审核通过后按开始日期与其他有效记录共同计算日/周上限和两类目标，不重复领取学时。
- 免测证明支持 PDF、JPEG、PNG，并兼容既有 WebP；单文件不超过 10 MB。服务端核验实际字节、哈希及格式，PDF 必须可解析且至少一页。运动打卡不接受 PDF。
- 照片原图单独保存于本机浏览器存储，不随记录提交清除，学生可下载或删除；浏览器清除站点数据和设备存储回收仍会影响可用性。上传 JPEG 副本保留图像像素与必要拍摄 EXIF，排除 GPS、身份等元数据。教师可查看拍摄时间、相机、曝光等允许字段；没有相应信息显示“无数据”，不得据此自动判无效。浏览器相机本身没有提供 EXIF 时不伪造拍摄信息。
