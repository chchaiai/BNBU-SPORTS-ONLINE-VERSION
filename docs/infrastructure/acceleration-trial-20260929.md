## 边缘测试方案（用户选择仅做无新增付费服务，暂不执行）

建议先创建 `accel-test.bnbusports.cn`，接入一个 EdgeOne 个人版站点。套餐官方标价 29.9 元/月；智能加速、HTTP/3 和超额使用存在额外费用，最终以账号下单页及计费规则为准。尚未购买、开通或改变生产 DNS。

1. 核查域名备案、账号可用加速区域、域名归属和新增域名证书能力。
2. 回源地址使用香港服务器，HTTPS 回源 Host/SNI 固定为学生站，验证证书。
3. 第一轮仅缓存 `/student/_assets/` 下的公开版本资源，遵循源站缓存响应；首页、runtime-config、API、带认证请求及非 GET/HEAD 请求绕过共享缓存。设置 Cookie 的响应不缓存。
4. 第二轮开启动态智能加速，API 继续绕过共享缓存；第三轮开启 HTTP/3，保留 HTTP/2 回退。三项分别测试，记录协议、缓存命中、TTFB、DOM 就绪时间、错误率和费用。
5. 直连生产域名作为对照。公开页面先测；登录业务需合适的隔离测试账号、跨域与来源配置后再测，不以健康接口代替业务验收。
6. 校园网、移动、联通、电信各做至少 5 轮交替测试；比较同一时间段中位数及尾延迟。未通过测试前不切换生产域名。
7. 试验结束可移除测试域名 CNAME、停用测试加速域名。购买前确认套餐续费设置、余额/用量限制；费用告警不等于硬性消费封顶。

```sh
sudo python3 /home/ubuntu/deploy-knowledge-image-route-20260929.py --rollback
sudo python3 /home/ubuntu/media-cache-trial-20260929.py --rollback
sudo python3 /home/ubuntu/transport-trial-20260929.py --rollback
```

两个脚本均保存原始配置、检查漂移、执行 nginx -t 后 reload。备份保存在 `/opt/bnbu-sports-production/backups/` 下对应目录。

知识库独立发布位于 `/opt/team-knowledge-base/releases/images-20260929/`，以 `compose.json` 管理候选服务；回退只切回仍保留的旧服务，不中断新服务上尚未结束的请求。初次尝试因检查了不存在的管理路由而中止，旧路由和旧服务保持可用；最终已改用 `/api/admin/overview` 并通过未登录 401 检查。长连接使原计划的容器原地替换无法安全推进，因此使用独立服务接管新请求。

官网复访资源传输量在当前桌面浏览器实测由 183,116 B 降至 7,092 B；这里比较资源量，不以两次网络时延差值作为因果提速证据。
