脚本体积按版本文件原始字节计算，已逐一匹配旧线上文件哈希；不包含单独的 runtime-config 和新增性能采集脚本，也不等于网络压缩后流量或实际速度提升比例。教师 76→1 只指运动记录列表阶段，不是整个页面全部请求。模拟的 9 学生、25 记录工作区首次读取共 18 次请求；选中有 3 条记录的学生后增加 9 次详情请求。

进行中、暂停和已结束待处理的学生运动会立即加载运动模块；其他页面保留草稿恢复及媒体处理入口。动态模块失败会显示重新加载提示。教师不同账号会话与请求代次隔离，避免已退出账号的延迟响应覆盖新会话。

## 性能采集与解释

`tools/performance/browser-metrics.js` 与学生 `js/performance.js` 使用相同脚本。只在两个正式域名运行，默认采样 20%，一个页面最多发送一次；诊断参数 `performance-diagnostic=1` 可强制采样。采集请求省略 Cookie 和 referrer，不发送账号、原始 URL、令牌或学生业务字段。专用日志不写 IP、User-Agent 或 referrer；原有站点访问日志仍按原配置运行。

Nginx 使用固定字段白名单、长度/数值校验与请求限速；合法采集返回 204，非法参数返回 400。日志为 `/var/log/nginx/performance-timing.log`，已有按日轮转规则覆盖，保留 14 份。采样为同源轻量请求，不依赖第三方采集服务。

计时为 0 可能表示浏览器未提供、连接复用或就绪标记尚未出现，不能解释为该阶段实际零耗时。`connect` 包含 TLS 阶段，不能与 TLS 相加。管理员页面没有教师工作区的 ready 标记；生产验证中教师域名的管理员样本 `ready=0` 不代表即时就绪。全零 ID 的记录来自采集接口健康测试，应排除统计。

腾讯云控制台已进入 `bnbusports.cn` 的套餐选择页面：个人版、1 个月，当前报价 9.9 元，含 50 GB/月加速流量及 300 万次/月请求。自动续费和协议复选框均未选中，订单未提交、费用未产生。报价截图见 `evidence/access-performance-20260930/edgeone-proposal.png`，最终价格以提交时控制台为准。

计划按下列顺序执行：

1. 取得本次新增费用及服务条款确认后，开通一个月个人版；建议试验总预算 50 元，含套餐和按量费用，不开自动续费。该预算是本次执行限额，不是已配置的云厂商强制账单封顶；先核对用量限制和费用告警能力，再启用付费附加功能。
2. 使用 `accel-test.bnbusports.cn` 测试域名核对接入区域、域名资格、HTTPS 证书、源站 Host/SNI 和安全规则。控制台“可接入”提示不能单独证明中国大陆节点接入资格。
3. 先验证静态资源缓存，仅对明确可公开的版本资源放行共享缓存；API、登录态内容、带认证/Cookie 的请求及非 GET/HEAD 请求绕过共享缓存。校验响应内容和缓存命中，防止缓存业务身份数据。
4. 再分别启用动态智能加速、HTTP/3，与直连和仅静态缓存交替对照。附加能力可能产生按量费用，以当前账号的功能和计费页面为准。每次只改变一个条件，记录冷/热缓存和协议回退。
5. 校园 Wi-Fi、中国移动、宿舍网络采用同设备同 URL 多次测量，比较首字节、首次绘制、就绪时间及失败率。达到可重复改善后，再评估正式域名切换。
6. 如果边缘方案没有改善真实故障网络，再评估服务器及数据库区域调整。现有证据不支持直接扩大 CPU、内存或购买高防；迁移决策需要链路对照和应用/数据库联合评估。

接入前需要用户确认新增预算与接受 [EdgeOne 服务协议](https://cloud.tencent.com/document/product/1552/90970)、[退款规则](https://cloud.tencent.com/document/product/1552/77390)。确认来源是浏览器工具的操作规则：接受有法律约束力的协议必须在该操作前确认；一般云服务购买还需要明确的商家、项目和预算。
