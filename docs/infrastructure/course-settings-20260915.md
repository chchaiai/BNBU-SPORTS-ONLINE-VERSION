# 教师课程设置排查、修复与部署（2026-09-15）

## 原因与已确认规则

已发布课程的保存分支只提交运动规则，跳过每日时间、打卡状态、课程日期和截止日期，随后提示成功。后端服务和数据库触发器同时禁止修改已发布时间安排。

用户确认：允许责任教师修改每日开始/结束时间、允许/暂停打卡；课程开始/结束日期及截止安排继续锁定。

## 界面检查结果

| 操作 | 结果 |
| --- | --- |
| 保存每日时间、暂停/恢复 | 补齐 PATCH、数据库规则迁移和保存后读取核对 |
| 课程日期、截止日期 | 已发布时只读，并说明锁定原因 |
| 最低/最多运动分钟、日/周次数、两类目标 | 接口字段齐全；逐项修改、保存、刷新验证通过 |
| 保存期间重复操作 | 增加同步锁、保存中状态及表单禁用；两阶段请求复用幂等键 |
| 规则接口失败 | 保持窗口并说明未全部确认保存；重试不重复写入已完成的时间设置 |
| 主窗口取消 | 未保存的时间修改被放弃，重新打开仍显示服务器值 |
| 保存补卡设置 | 独立接口正常，真实本地 HTTP/页面保存通过 |
| 检查结算条件 | 独立读取正常；条件不满足时禁止确认结算 |
| 删除课程、删除确认与取消 | 确认门禁及取消正常，本次未执行课程删除 |
| 综合名单/报告导出、更早报告 | 代码检查均调用对应接口并处理失败；本次未新建结算报告或执行导出验收 |

课程结算和删除区块曾共用同一 React key；现已分别使用 settlement/closure 标识，重复渲染警告消失。
