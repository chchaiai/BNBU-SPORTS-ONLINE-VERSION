## 故障与回滚

任务表 `v81_ai_review_jobs` 保存组织、记录及材料版本、状态、尝试次数、租约、模型/策略版本、建议、标记、安全错误码和时间；相同记录/版本只能有一个任务。最多重试三次，4 分钟租约，外部处理超时 180 秒。多进程通过 PostgreSQL 行锁领取，回写校验租约和当前材料版本。模型自由文本不会作为操作执行或进入教师页面。

查看任务状态可按组织和状态聚合；凭记录 ID 关联任务及公开 HTTP 请求编号。云服务编号见 `AI_MODERATION_RESPONSE`、`AI_VISION_RESPONSE` 日志。权限/额度/响应格式/超时错误显示 AI 暂不可用，交教师审核；恢复服务后不应无界重放失败任务。

停用初审：在当前 release 的 `production.env` 设置 `AI_REVIEW_ENABLED=false` 后按原 Compose 流程仅重建 Backend；已存建议保留，教师继续审核。紧急阻止模型调用也可停用专用 TokenHub Key，IMS 调用仍须通过应用停用关闭。

接口文档同步的即时回滚目标为 `ai-review-ui-20260917`；应用回滚目标为 `student-network-20260916`（整个 AI 功能回退）或 `ai-review-20260917`（仅回退主题补丁）。切回相应目录和固定镜像，使用其原有密钥挂载，然后校验两容器健康和公开入口。0083 为新增表，旧版本读取自身注册迁移清单，额外表可保留；不删除新任务、预算或迁移记录，不恢复旧数据库覆盖新提交。回滚流程已准备，未在生产主动触发回滚演练。

## 剩余限制

1. 视频按每秒抽帧，最多 15 帧；音频与间隔画面未审核，视频至少黄色复核。不能将本功能表述为完整音视频合规审核。
2. 重复检测仅比较同组织已受理材料的相同哈希；裁剪、改编码、截图等变体可能漏检。相同材料只是线索，不等同作弊。
3. 模型无法证明拍摄时间、身份、完整时长或真实性；绿色仍需教师最终决定。本轮覆盖合成材料和分级规则，没有用真实学生数据建立准确率/误报率基准。
4. 单实例串行消费，5 秒轮询；未做大规模并发和长视频积压压力验证。持续积压时应先核查处理耗时及费用，再评估扩容。
5. 旧 PENDING_AI/TECHNICAL 记录不自动重判或补跑，继续通过现有总管理员受控人工模式转交责任教师。新提交均进入教师待审。
6. 仓库正式 Contract 发布校验仍要求 `2.0.12-contract`，当前及本任务开始时的 OpenAPI 都是 `3.0.0-v81-local-draft`。完整 `npm run contract:check` 因此未通过正式版本兼容性步骤；本轮新增 AI 枚举已完成注册、结构校验和运行文档同步。此处不宣称完成旧版 Contract 冻结发布。
7. 模型账单与控制台用量有延迟；本轮未把免费额度或预留金额声明为实际已付费用。
