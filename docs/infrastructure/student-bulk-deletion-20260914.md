# 管理端学生批量删除部署记录

2026-09-14，已部署到香港生产管理端。入口：超级管理员 → 账户管理 → 学生账户。

## 使用方法

1. 逐个勾选学生、选择当前页，或选择当前筛选结果。支持跨页保留选择；变更筛选条件或刷新会清空选择。
2. 点击“批量删除”，核对固定名单和人数，填写删除原因，勾选知情确认，并输入“删除 N 名学生”。
3. 确认后逐个处理，显示每人的结果。可停止后续删除；已完成的删除不可恢复。
4. 遇到错误立即暂停。版本冲突等明确拒绝的记录应刷新后重新核对；网络断开、服务异常等结果未确认的请求保留原请求内容及幂等键，点击“核对结果并继续”重试。本窗口刷新后保留批次，不自动继续。

删除范围沿用现有永久删除：学生账号及全部课程关系、打卡、凭证、审核、学时、相关申请和成绩；媒体清理沿用现有队列。每名学生为独立事务，整个批次不提供整体回滚。权限沿用后端 SUPER 校验，未扩大普通管理员权限。
