# Stage 20A Export、Production 与跨端联调前置决策包

生成日期：2026-08-05。状态：`PROPOSED / USER_APPROVAL_REQUIRED`。本文件给出互斥选项和推荐方案，但**推荐不构成批准**，不能据此修改 OpenAPI、Prisma、Migration、runtime coverage 或客户端。

当前边界：四个 Export operation 继续返回 `SYSTEM_MODE_UNSUPPORTED`；`0011`、Export 表、ExportJob、worker、artifact 和下载 URL 均不存在。Backend Operation Coverage Gate 为 YES；Export Business、Client Integration、Staging 和 Full Production Gate 均为 NO。

## 1. Gate 与批准规则

- 每项只能在“用户批准”列写入明确选项编号、批准日期和批准证据；空白或推荐值均等于未批准。
- Export 必须完整批准 EXP-DEC-01–12，随后冻结 ADR、OpenAPI、状态机和 0011 设计，才可进入实现。
- Production 必须完整批准 PROD-DEC-01–14，并把 ADR-070–074 逐项闭合，才可改变 Production Gate。
- Client Integration 必须批准 INT-DEC-01–12，且 staging 可用，才可修改第一个客户端。
