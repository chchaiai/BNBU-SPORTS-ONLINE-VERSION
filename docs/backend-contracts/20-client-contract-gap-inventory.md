# Stage 20A Client Contract Gap Inventory

生成日期：2026-08-05。此清单是 Android/Web **只读审计**；没有修改客户端。权威合同始终是 `docs/backend-contracts/openapi.yaml`。

| 端      | 模块                           | 当前实现                                                                                              | 权威合同                                                                           | 差异                                           | 风险                                              | Stage 20B 动作                                                                    |
| ------- | ------------------------------ | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------------- |
| Android | Authentication                 | 手写 `/auth/login` 等旧路径，只持久化单 bearer token；无 refresh rotation/reuse/logout family         | `/api/v1/auth/password-login`、refresh、logout、`/me`；五字段错误 envelope         | 路径、DTO、token 生命周期均不一致              | 会话无法安全恢复/撤销，错误解析可能依赖 body 文本 | 先生成 Auth DTO；实现 Access/Refresh 安全存储和 401 单次 refresh；移除旧 fallback |
| Android | Current User / Email binding   | 旧 `/student/profile/contact/*` 与手机号状态                                                          | `/api/v1/me` 与两步 `/me/email-verification-challenges`                           | 旧流程与邮箱唯一 challenge 不一致              | 可能继续提交手机号或绕过双邮箱验证                | 已接正式邮箱 challenge；删除手机号 DTO/入口；换绑同时提交当前和新邮箱验证码       |
| Android | Course/ClassSection            | `/student/courses` 旧聚合                                                                             | `/api/v1/courses`、`class-sections`，学生读取依赖 ACTIVE Enrollment                | 资源边界和分页不同                             | Course 与 ClassSection 被混为旧 DTO               | 生成分离模型，按 Enrollment 投影组装 UI                                           |
| Android | Enrollment/QR Join             | `/v1/course-invites/{code}` 与 `/courses/{id}/join`，token 语义不同                                   | token path→JoinCapability header→atomic Join；ACTIVE Enrollment                    | 缺 capability、独立 header、幂等和精确结果     | 重放/权限/身份创建错误                            | 按 OpenAPI 重写 QR flow；不复用 Access Token 代替 capability                      |
| Android | Roster                         | 无学生正式 Roster 操作                                                                                | STUDENT 禁止 Roster                                                                | 基本一致，但旧 UI 数据可能含派生课程信息       | 不应新增学生名单读取                              | 保持禁止；只消费 Enrollment projection                                            |
| Android | Session                        | 本地 `ExerciseSessionStore/Controller` 和计时快照                                                     | 服务端 8 个 Session operation、active recovery、7200 秒、fail-closed reconcile     | 本地状态目前可成为事实，尚未绑定后端 version   | 双设备/离线时长不可信                             | 服务端 Session 为权威；本地只缓存 UI/recovery intent                              |
| Android | Media                          | 旧 multipart `/upload/proof`，返回 URL/cosKey                                                         | initiate→private PUT→confirm→bind→processing→AVAILABLE；无 storageKey/public URL   | 全流程、身份和 projection 不一致               | 证据泄露、跨 Record 复用、永久 URL                | 替换为 mediaId 状态机；production 删除旧 multipart adapter                        |
| Android | Record                         | `/sport/records`、小时数/旧证明 DTO                                                                   | Session 派生整数秒；DRAFT→SUBMITTED；expectedVersion；每日唯一                     | 路径、状态、duration、media 绑定不同           | 客户端提交非权威 hours                            | generated DTO；按 Record lifecycle 和服务端 seconds 展示                          |
| Android | Review                         | DTO 含旧 teacher feedback/internal note 风险                                                          | 学生只见 safe currentReview，永不见 `internalNote`                                 | 旧 response model 可能接受内部字段             | 隐私泄露                                          | 只生成 Student projection；删除内部 note 映射                                     |
| Android | Score                          | 本地 summary/grade 与 endurance calculator                                                            | 后端 Score revision、PUBLISHED/LOCKED projection；客户端不计算正式分               | 本地计算/小时模型与 Decimal revision 不一致    | 展示非正式成绩为正式事实                          | 只展示后端 published projection；本地计算明确标为非权威或移除                     |
| Android | Export/Audit                   | 无正式 API                                                                                            | Export 四路 503；Audit ADMIN-only                                                  | 无功能不构成实现                               | 若复用旧下载入口会误报                            | 不新增；处理 503，不显示 Audit                                                    |
| Android | 通用协议                       | 手写 Gson，mutation 自动新 key；无统一 cursor/requestId/error adapter                                 | data/meta、cursor、Idempotency-Key 重放、version、五字段 error                     | 不保留用户意图 key；无 requestId/cursor        | 超时重复写、无法诊断                              | 建统一 transport/interceptor/result；同一 intent 持久化 key                       |
| Android | Base URL/Mock                  | debug 默认旧 IP `/api`；release 才强制 HTTPS；显式 Mock user/workspace                                | local/staging/production 显式 `/api/v1`；不得 fallback                             | 默认目标与 prefix 错；Mock 可进入主状态        | 误连旧后端、假数据被当事实                        | 三环境显式配置；production build 禁 Mock/旧 host                                  |
| Web     | Authentication                 | 任意非空账号密码进入；admin localStorage 30 天；ChatGPT headers 与 BNBU Auth 无关                     | password-login/refresh/logout/me，服务端 role/session 为权威                       | 没有真实认证、token family 或权限              | 完全绕过后端身份                                  | 建独立 Auth adapter；批准 Web refresh transport 后实施；移除本地 role session     |
| Web     | Course/ClassSection/Enrollment | 教师页面使用静态/本地结构                                                                             | 权威 Course/ClassSection/Enrollment operations、teacher ownership、ADMIN read-only | DTO、路由、version、scope 未接入               | 教师/管理员职责混淆                               | 先接真实 read projection，再逐 mutation 加 version/idempotency                    |
| Web     | Roster                         | sessionStorage Mock、自建 `teacher/courses/...` 路径、九类旧状态、本地 CSV export                     | 13 个 Roster operation、六类 alignment、typed resolution、ignore 503               | 路径、状态、版本、权限、文件处理均不同         | 会直接违反已冻结 Roster 合同                      | 用 generated types 替换 adapter；保留 Mock 仅 development；删除本地业务 export    |
| Web     | Review/Score                   | 页面和本地数据模拟审核/成绩                                                                           | responsibility Teacher Review、双 version；Score revision/approval/publication     | 没有真实 requestId/version/role projection     | 覆盖/重复决定，展示 working 给学生                | 按 `Record→Review→Score` 纵向接入；ADMIN 不代审                                   |
| Web     | Export/Audit                   | Roster 有浏览器即时 CSV；admin Audit 是 local Mock JSON                                               | Export 四路 503；Audit 仅 org ADMIN、脱敏、cursor、read-of-read                    | 本地 Export 假实现；Audit 字段/权限/分页不一致 | PII 导出和假审计                                  | 禁用正式 Export；Audit 页面改接权威 list/get；不显示任意 metadata                 |
| Web     | Error/pagination/concurrency   | 私有 `AdminServiceError`、页码/local revision                                                         | 五字段 error、opaque cursor、Idempotency-Key、expectedVersion                      | 协议不一致                                     | 错误分支和并发行为不可移植                        | 统一 HTTP result 和 code-i18n；cursor 不解析；stale 强制刷新确认                  |
| Web     | Base URL/Mock                  | 无统一 API base URL；admin localStorage、roster sessionStorage、静态 seeds；production 仅隐藏演示入口 | 显式环境、production 无 Mock、失败不 fallback                                      | 数据层仍是 Mock，即使入口隐藏                  | UI 可把本地事实当服务端事实                       | 增加 build/runtime env schema；production bundle 测试 Mock module 不可达          |
| iOS     | 全部                           | 仓库不存在 iOS 工程                                                                                   | 与 OpenAPI 相同的完整合同                                                          | 无实现、无构建和测试证据                       | 不能声称三端联调                                  | Stage 20B 不自动创建；另行批准工程、生成器、Keychain 和模块顺序                   |

盘点结果：21 个差异行；其中 Android 13、Web 7、iOS 1。`CLIENT_GAP_INVENTORY_GATE=YES` 只表示差异已登记，不表示已修复或联调完成。
