# Demand 2026-09-12 业务与数据补充

本文记录 demand.md 及用户确认形成的本轮候选实现契约。OpenAPI 当前版本仍为 3.0.0-v81-local-draft；正式发布工具的旧版本门禁未通过，不表示已发布新的正式 Contract。

## 长期身份与数据保留

学生身份继续由组织和学号唯一确定，已验证邮箱长期绑定 User。匿名 capability 不允许认领已经验证的身份；本人登录后通过 member capability 加入课程，复用 User 和 StudentProfile。学院、专业、dateOfBirth、regionCode 写入长期档案，已填写内容在再次入班时保留；老客户端省略可选字段仍可兼容，学生网页采集完整字段。出生日期为 1900 年起至当日的真实日期，地域为 31 个大陆省级区域加香港、澳门、台湾、其他。

移除成员仅结束 Enrollment。删除课程通过 retiredAt 和 CLOSED 退休课程，结束成员关系并撤销邀请；运动与审核事实保留。删除教师保留学生及其历史。只有 SUPER 管理员可以单独执行学生全量删除，并校验当前版本、学号确认及原因；子管理员 USER_ACCOUNTS 权限不足以执行此操作。

## 课程配置和历史补录

minimumMinutes 允许 1–1440 整数；dailyLimit、weeklyLimit 为正整数。日/周上限共享课程相关与自主运动，两类目标总计仍为 1200 分钟，单条计入仍最多 60 分钟。统计使用运动所属业务日期，选择满足日/周限制的最大有效分钟组合。模板提供默认值，已发布规则保持既有冻结规则。

v81_history_settings 保存教师配置的 enabled、earliestDate、latestDate、version。范围限当前学期，实际声明必须开始和结束于今天之前；允许早于入班日期。声明产生真实历史日期的已完成 Session 及 v81_history_session_sources，冻结当次配置版本；不生成实时计时片段。课程正常提交期内开放，课程退休、成员退出、常规截止后拒绝新声明及首次提交。关闭范围只禁止新声明，已创建草稿仍遵循正常提交窗口。

历史记录投影 recordOrigin=HISTORICAL，普通记录为 LIVE。历史补录必须有凭证并人工审核；审核前不计入时长。FILE_PICKER 只放开历史运动凭证和原有申请场景，普通实时打卡保持现场采集要求。历史计入使用同一个课程日/周算法。

## 文件与照片

MediaType 增加 DOCUMENT，仅限 EXEMPTION_APPLICATION 的 application/pdf。声明、文件大小、哈希、PDF 结构页数、病毒扫描、所有者和目标关系校验全部执行；最多 3 个申请材料的现有限制保留。Migration 0068 将材料提交触发器扩展为 IMAGE 或 DOCUMENT/PDF。

safeMetadata 保存可验证的相机信息：拍摄时间、厂商、设备型号、焦距、光圈、ISO、曝光时间、方向、尺寸；PDF 返回页数。客户端和服务器继续排除 GPS 等位置数据。不存在的相机信息显示无数据，网页相机本身不产生的 EXIF 不伪造。

手机网页将原始照片存入按平台用户隔离的 IndexedDB，提交不会删除，个人中心可下载或删除。JPEG 上传副本保留原压缩像素和允许的 EXIF，剔除位置/扩展元数据。浏览器清除站点数据或卸载会丢失本地副本；Web 不保证自动写入系统相册，学生可主动下载原图。
