## 根因与修复

1. 视频强制加载约 32 MB FFmpeg WASM 完整转码，原件预览被 pending 状态拦截；线上所有静态资源 no-store。新增浏览器 H.264/AAC 本地编码、原件即时预览；不支持者保留 FFmpeg worker，版本化组件 URL 和 Nginx 缓存配置待部署。原生编码声音首测发现 muted 导致音轨静音，已修正为仅路由到编码器并通过 RMS 声音回归。
2. 详情原始 source=media:ID，从未为封面换取授权地址。现在每次打开换取短时地址，图片与视频首帧直接由私有对象存储读取；签名只驻内存。
3. 文案删除及原生相机输入完成。新拍视频返回时校验 10 秒。
4. 旧后端 assertCreditableDuration 明确允许低门槛提交，仅计入为零。创建及提交都阻止，学生结束页不再提供提交；旧正式历史不改写。
5. 课程删除有有效邀请码时写 COURSE_RETIRED，旧 course_invites_revoke_shape_check 只允许 TEACHER_REVOKED 或有换码后继。云端强制回滚诊断和本地新回归均复现 SQLSTATE 23514 / Prisma P2039 / HTTP 500。0071 扩充该检查约束以兼容课程退休，保留所有旧行和换码来源。
