# 学生端三项页面修复与部署

用户要求：删除通知页“补证倒计时（当前无待办）”按钮，删除课程页“加入另一门课（同学期已有课程）”按钮，在打卡“准备开始”中显示每日允许打卡时间段。

## 根因与修复

- 通知页没有补证待办时仍渲染禁用的倒计时占位按钮，现已移除该空状态按钮。真实补证待办与通知读写逻辑继续使用既有能力。
- 课程页已有同学期课程时仍渲染禁用的加入按钮，现已删除该分支。首次正常入班入口继续按原权限显示。
- 后端已经提供每日起止时间，真实API模式却用核验提示替代了时段。现在展示课程的每日允许打卡时段并注明北京时间，全天配置显示全天，不可用配置显示暂不可用。实际开始时仍由后端核验课程开放时间及本人补练资格。
