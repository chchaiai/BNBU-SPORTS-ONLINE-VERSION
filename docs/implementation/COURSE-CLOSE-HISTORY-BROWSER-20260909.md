# 教师课程关闭与历史访问

2026-09-09。依据教师业务文档 5.3：关闭阻止新的业务起点，关闭前合法业务继续处理，关闭不等于结算或归档。

实现：教师“全部”课程页签保留后端返回的 CLOSED/ARCHIVED 课程，状态不再统一写成 ACTIVE；进行中页签仍按 ACTIVE 筛选。非当前学期暂显示“其他学期”，避免错误使用当前学期名称。读取后端授权的教师完整分页成员列表，再按课程关联，历史学生/体测/成绩可以继续加载；未放宽服务端权限或 UUID 校验。

现有课程设置弹窗增加关闭原因、业务影响确认与关闭按钮，按版本及幂等键调用已有 close 接口。丢失响应后按当前用户、课程保存原请求，刷新可重试；关闭后禁用课程设置保存，继续显示原有结算与历史入口。组件保留后台权限及状态冲突反馈，不把关闭作为清空待办的动作。
