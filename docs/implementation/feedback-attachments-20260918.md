# 师生反馈与附件发布验收（2026-09-18）

已增加教师“问题反馈 / 我的反馈”，与学生反馈进入同一管理员处理列表。管理员列表展示学生或教师身份、真实姓名、学号或工号及邮箱，详情支持附件预览 / 下载。教师可查看本人反馈的完整回复历史，并从通知跳转。

师生均可上传最多 5 个附件。图片每个 10 MB、视频 50 MB、其他文件 20 MB；支持 JPG/JPEG、PNG、WebP、MP4、MOV、WebM、PDF、DOCX、XLSX、PPTX、ZIP、TXT、CSV。上传区提供分类按钮、图片缩略图、大小、数量、上传状态、移除操作；教师端支持拖拽。反馈必须成功绑定已验证的本人附件后才提交。

## 权限与存储

附件沿用现有私有对象存储及生产病毒扫描。上传后复制到仅服务端可写的新对象，再校验大小、文件签名并扫描；避免尚未过期的上传链接替换已接受附件。访问链接 5 分钟有效。文档强制下载；图片和视频可预览。学生 / 教师仅查看本人附件，管理员需同组织且具备既有反馈处理权限。附件上传额度每账号每天最多 40 次。
