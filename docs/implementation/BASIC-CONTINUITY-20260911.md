## 根因与修复

1. 已拍照片、视频只保存在 `ui.checkin.drafts`，Blob URL 仅对当前页面有效，没有保存媒体字节。真实本地会话复现：刷新前 1 张照片，刷新后 0 张；服务端 sessionId 相同，运动会话仍存在。
2. 重开页面默认显示首页，没有自动返回本机正在进行或已结束待提交的打卡；回到前台只刷新系统公告，没有刷新服务端运动状态。

新增 IndexedDB 凭证存储，以学生身份、运动/补证记录和凭证 ID 定位，保存原始 Blob，重开时生成新的 Blob URL。拍摄完成立即保存；存储失败明确提示勿关闭页面，不伪称已持久保存。提交成功、明确删除/放弃、注销账户时清理相应草稿。申请持久存储的结果由浏览器决定。

启动加载账户后恢复媒体和打卡页；本地已有运动信息与服务端当前会话校准，切回前台重新读取服务端时间和版本。常规校时仅更新计时文字，避免替换正在播放的视频或相机。运动说明、提交幂等键继续复用原有保存逻辑。无数据库迁移，无业务规则调整。

## 使用边界及剩余依赖

已完成照片和已结束录制的视频可以在同一浏览器、同一站点重新打开后恢复。操作系统仍可能冻结或回收网页，相机不能保证在后台持续工作；清除浏览器站点数据、隐私窗口销毁或浏览器强制回收存储不在恢复保证内。页面若提示材料未保存，请保持打开并处理存储问题。

新版本无法找回旧版本已经丢失的照片/视频。仍打开着旧版本且有未提交材料的页面，应先完成提交，再重新打开使用新版本。跨设备同步未新增，实际学时始终由服务端判定。没有待用户批准的部署事项；手机真机后台策略可作为后续专项验收。
