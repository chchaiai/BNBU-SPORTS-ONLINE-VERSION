学生自行注销须验证当前邮箱，验证码绑定本人、本次登录会话及账号版本。错误验证码累计五次锁定，过期、跨账号、跨会话和旧版本确认均拒绝。验证后按用户确认的规则调用现有学生删除流程，删除账号、课程关系、运动和审核历史、登录会话；媒体进入现有清理队列，必要操作审计保留。界面已开放入口、重新发送验证码和最终确认。

课程相关或自主运动目标为数值 0 时，该类别置灰并禁用，开始运动入口校验旧选择状态。初始化优先选择仍开放的类别。已开始的运动仍可恢复并完成。

课程目标为 0 时，历史课程运动记录的学时按自主运动目标计算。保留记录的原始运动类别和审核结果，沿用各记录的最低时长、单次上限、每日与每周次数，以及自主运动目标上限。学生进度、教师学生列表、管理员汇总及课程提醒使用同一转计规则。
