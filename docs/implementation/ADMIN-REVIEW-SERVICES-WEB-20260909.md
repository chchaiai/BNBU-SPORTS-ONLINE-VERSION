# 总管理员模板、人工审核及 OCR 网页接线

2026-09-09。本地候选实现；用户明确批准三个最小必要表单。复用管理员侧栏、页面和现有表单样式：统一模板位于全局规则；人工审核与 OCR 位于系统模式内容区，既有模式控制顺序保留。

## 已实现

- 总管理员发布现行业务规则模板，填写名称，读取最新版本；规则值由后端固定，不能任意更改。
- 选择当前学期课程、读取人工模式，填写原因后开启或关闭；后台验证课程范围、权限及版本。关闭人工模式不解锁未经验证的 AI 自动通过。
- OCR 服务商、地域、超时、启停、变更原因与版本保存；展示任务进程及执行条件，说明 CVM 角色凭证与云连通性仍需验证。
- 三项写入均先保存用户范围内的会话提交意图；响应丢失、刷新后仍用原键和原正文重试。明确放弃重试后重新读取版本；后端保留幂等和版本冲突规则。
- 分管理员不展示这些总管理员表单；后端 SUPER 权限检查保持有效。Demo 模式不生成真实表单。

## 原始失败与处理

- [浏览器第一轮](admin-review-services-browser-first-20260909.txt)：必填标签含无障碍“必填”文字，测试使用精确名称找不到模板输入；改用包含匹配。
- [浏览器第二轮](admin-review-services-browser-second-20260909.txt)：原生选择器标签还包含选项文字，测试找不到 OCR 服务商；改用包含匹配。该轮已完成模板及人工模式恢复。
- [Docker 首轮](admin-review-services-docker-20260909.txt)：专项命令缺少 npm run build，找不到 dist/app.module.js；追加编译后复测通过。
- 三轮共留下三个明确标记的合成模板版本，不删除不可变历史。测试后主课程人工模式开启、OCR恢复DISABLED。

## 剩余依赖与交接

真实腾讯云 OCR 仍依赖 CVM 角色、运行进程与网络连通性；本地保存配置不证明云识别可用。AI自动通过仍需要真实样本验证，本次按人工审核范围交付。

学生游泳前后材料步骤及本人结算网页按用户决定暂缓，后台能力保留。全范围审计见 [原始30项主流程](BUSINESS-CHAPTER-AUDIT-20260909.md)；原发布兼容及仓库布局检查尚未通过，不宣称正式发布或云部署完成。
