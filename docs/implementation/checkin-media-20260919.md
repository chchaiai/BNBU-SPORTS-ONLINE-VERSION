## 修复

1. 已授权学生读取本人草稿 evidence-context 时，恢复同组织、同学生、同运动、EXERCISE_RECORD 且 AVAILABLE 的材料。已提交记录仍使用正式关联，教师读取逻辑保持原有权限检查。
2. 提交前核对服务端材料，以已有媒体标识或原文件 SHA-256、大小和类型匹配本机草稿，复用已验证的视频，避免重新占位。恢复出本机缺失材料后，先显示供学生核对，再次点击才正式提交。
3. 上传幂等键、初始化、对象上传、确认、绑定、验证成功各阶段持久化。上传已开始的草稿禁用本机删除，避免与服务器凭证集合分离。
4. 失败时清除进行中进度并说明凭证保留；材料不一致使用准确提示。明确的 4xx 拒绝后更新提交键，网络结果不明仍保留原键。提交指纹包含版本，已成功受理后的本机保存异常不会误报打卡失败。
5. 恢复的服务器素材无需本机 Blob 即可提交；预览通过原有受控访问接口读取。
