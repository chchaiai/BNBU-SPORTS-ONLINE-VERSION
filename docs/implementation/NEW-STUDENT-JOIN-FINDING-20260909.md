## 原因核对

teacher-data.ts对无progressTarget的新课程投影两类目标为0；teacher-workspace.tsx进入课程将这两个0带入form。真实模式只显示固定总目标1200分钟，并把原有两类目标输入隐藏在Demo分支，saveCourseSettings因此拒绝新课程。另，发布正文的运动门槛和每周次数固定取模板默认值，没有教师选择入口。

业务文档20-teacher-flow.md第3章与职责表要求：教师分配两类非负目标、合计1200分钟，并从模板选择30/45/60分钟门槛、每周2/3/4条。不能把旧的有预置目标课程发布证据当作全新课程可发布的证明。
