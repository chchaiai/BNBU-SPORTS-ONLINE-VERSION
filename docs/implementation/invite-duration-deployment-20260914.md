## 修改

教师可输入至少5分钟的整数时长，例如121分钟、1440分钟（1天）、10080分钟（7天）；默认30分钟。解除页面input max及JavaScript上限、后端DTO Max(120)、领域计算的相对与绝对时间上限。校验有效数值及可表示日期，继续按现行业务在学期结束前截止。

二维码与手动邀请码共享有效期。自然到期后不允许新登记；此前已登记流程只有固定10分钟宽限；撤销、关闭入班、关闭课程和学期失效继续立即终止入班资格。已发出的二维码保留原到期时间，教师生成新码时才使用新时长。

页面中英文提示、当前开发OpenAPI及生成文档、3份涉及邀请的业务文档已同步。接口字段仍为expiresInMinutes或互斥的expiresAt，无新接口，无数据库迁移，无正式Contract版本发布。
