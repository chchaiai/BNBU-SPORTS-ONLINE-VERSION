# 教师名单进班检查简化（2026-09-20）

用户要求：选好导入名单的列后直接检查未进班学生，简化后端术语，测试后部署并本地存档。

## 已实现

- 课程卡入口改为“检查学生进班”。导入仅两步：选择名单，确认学号/姓名等列后点击“检查谁还没进班”。
- 真实客户端依次上传原件、确认名单、执行核对、读取结果，成功后直接展示结果；上传、确认、核对分别保留稳定重试标识。
- 检查失败明确提示“名单已保存，但进班检查尚未完成”，重试复用已经上传的原件；未完成检查不显示成功。
- 默认显示“未进本班”，涵盖还未加入和加入其他班；“已进班且信息一致”“需要核实”“全部检查结果”分组。保留权威六类判定，重复学号/信息不一致不冒充缺席或已正常入班。
- 精简为学号、姓名、进班情况、说明与建议、详情五列；隐藏版本号、英文状态与接口说明。详情保留教师核实入口。
- 学生加入后可刷新检查，重置列表页码及旧详情，避免留在过期分页。
- 导入窗口固定标题和按钮，先选列再预览；检查页小屏不横向溢出。新增静态文字补充英文资源。

## 测试

- 名单专项 16/16：CSV/XLS/XLSX、行数限制、原字节、确认/检查重试、服务端结果映射。

- 全量英文覆盖检查仍有其他页面既存缺项；本次名单页静态文字无缺项，未将全量检查记为通过。
