# 成绩未确认请求遇到访问拒绝

2026-09-09。现有成绩 catch 分支在 401、403、404 时删除原请求。这些响应只描述当前访问结果，不能证明此前响应丢失的写入没有成功；因此改为保留原请求，继续显示现有错误。成功响应及明确版本冲突、输入校验失败维持原处理。未更改界面元素、布局或后端权限。

测试在本地 Docker 后端实际写入成绩后丢弃响应，再通过浏览器路由注入 403；断言 sessionStorage 仍存在原键，然后刷新并重试，断言原键、原体和版本完全一致。相同脚本继续检查并发冲突不自动覆盖、明确重试成功及发布丢响应跨刷新恢复。

初次 grade-access-denial-browser-20260909.txt 退出 0，草稿版本保持 5，发布版本保持 8；初次注入使用未在协议列出的 AUTH_FORBIDDEN，能够证明 HTTP 403 分支，但不作为协议错误码证明。最终脚本使用 PERMISSION_DENIED、details 与 requestId，并另存 grade-access-denial-browser-final-20260909.txt。Portal TypeScript 检查退出 0，grade-access-denial-typecheck-20260909.txt。

本次访问拒绝为浏览器故障注入；真实后端保存、冲突、发布、幂等重放均使用运行中的 Docker 服务。401 刷新令牌、实际撤权再授权、404 恢复及重新登录后的浏览器操作不由本次测试证明。最新后端完整全量仍是十九轮 97/97，本次未修改后端且未重复全量。
