## 交接与剩余工作

种子与教师脚本接受 `V81_CLOSED_APPS_RUN`（小写字母/数字/连字符），`replay` 是完成完整成功链的独立轮次。首次历史私有文件为 `closed-applications-browser.json`，后续按轮次存储。已批准轮次再次运行会跳过写入，不能将只读重跑当作新的丢响应验证。

本轮不证明全部认证功能完成：认证分配调整/撤销及历史展示仍需完整网页接线；申请退回后真实补材料与累计三图仍待验证；关闭后名单/OCR、同批续传及完整关闭摘要仍待完成。当前部分批准详情仍沿用旧“重新处理”入口，不代表已批准申请可以再次进行普通审核，后端状态约束继续执行。

生产 COS/CVM/PostgreSQL、生产邮件和真实 AI 服务未验收。人工审核优先；本地存档，不推送或部署。
