# 教学审核与运动数据看板 · 2026-09-21

## 已发布

正式管理入口：https://www.teacher.bnbusports.cn/

发布：`admin-insights-20260921`；前一版本：`proof-storage-pixels-20260920`。Backend / Portal 健康，10 个后端运行文件、9 个 Portal 公网资源及 1 个学生端文件摘要核对通过。未登录访问统计接口返回 401。

## 功能

- 教师打卡审核增加班级筛选；记录队列、学生和下一位学生均遵循所选班级。
- 管理员在教师账号详情编辑姓名和管理员备注；组织和账号管理权限校验、乐观版本控制、幂等保存、事件审计。
- 课程目录展开后查看当前班级全体在班学生，进入个人打卡列表或凭证相册。
- 管理端打卡支持班级、姓名/学号/运动/课程文本、起止日期、审核流程状态、运动类别和学时类别筛选。
- 打卡显示开始、结束和提交时刻，精确到秒，教师/管理员统一北京时间。
- 显示筛选后的总记录数、总页数，支持首末页和指定页码。
- 修复学生端把课程括号内星期当运动名的规则；对旧课程相关记录的星期名称在读取时兼容显示，不修改原始打卡内容。
- 总管理员独有运动数据看板：关键指标、折线面积图、环形图、频率直方图、横向条形图和每周时段热力图。支持近 7/30/90 天、日期与班级联动筛选、SVG 图表和 CSV 数据导出。
- 业务事件页面区分操作结果与事件消费状态，解释非管理员待办及对应业务入口，保留原始事件状态。

## 图表口径

打卡排除 DRAFT/CANCELLED；参与人数按学生去重；频率按学生有打卡的自然日去重；实际运动与计入时长分别统计；教师审核按审核发生时刻统计，重复人工审核各计一次；运动时段按开始时刻北京时间分组。日趋势补齐零记录日期。界面展示的汇总覆盖完整筛选范围，不局限于记录第一页。默认最近 30 天，最长 367 天。

布局参考腾讯云可观测平台的统一过滤与分组图表面板，图表按运动数据类型选择。
