# 名单检查按钮与重复导入修复（2026-09-20）

## 修改

- 四种结果改成紧凑、可点击的按钮，选中按钮以蓝底和勾号标识；删除重复的下拉筛选。
- 四类分别为未进本班、已进班且信息一致、信息待核实、班内多出学生。名单外在班学生从信息冲突中分开，不再将全部结果作为第四种情况。
- 增加持续显示的大字结论：名单中多少位学生已在本班，并分别说明信息一致、信息冲突、未进班、重复学号和名单外学生。
- 身份冲突保留权威判定，其学号确实在本班时明确显示已进班但信息待核实；重复身份不推测入班情况。
- 相同文件再次导入原先收到 ROSTER_IMPORT_DUPLICATE 后变成通用错误。现核实当前原件 SHA256、工作表与所选列解析结果，复用已经确认的当前名单并重新检查最新成员。
- 公共错误响应不提供内部名单 ID，因此使用有课程权限控制的原件读取接口验证文件。不会依赖可能被过滤的错误详情。
- 选列不同或重复的是历史名单时显示具体指引，不静默采用过期名单。确认响应丢失后可读取已确认结果继续。
