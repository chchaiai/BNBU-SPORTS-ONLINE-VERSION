# 正式学期切换接口

2026-09-08 14:53。新增 POST /admin/semesters/{id}/switch，要求幂等键、目标 expectedVersion、原当前 currentSemesterId/currentSemesterVersion（无当前学期时两者为 null）。SEMESTER_MANAGE 授权在入口和事务内核验。

现有幂等服务以 Serializable 事务执行命令；取得组织锁后检查正常模式、目标存在、组织时区开始日期、目标 UPCOMING、原当前与目标版本，以及旧学期所有课程正式报告和待办。成功后旧当前归档、目标成为当前，各自版本加一，追加 CURRENT_SWITCHED 事件保存前后值与检查结果。数据库既有唯一索引保证每组织至多一个当前学期。归档学期不能恢复；业务历史不删除。
