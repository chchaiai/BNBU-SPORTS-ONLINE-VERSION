# 学生媒体格式与失败提示修复（2026-09-20）

## 已核实原因

- 第一张截图 requestId `afba2be3-981d-4d69-9469-471ff65f3868` 对应 2026-09-18 21:47:12（北京时间）的图片确认失败。声明 PNG，原对象实际 JPEG；大小 6,677,669 字节及 SHA-256 均与声明一致，像素解码成功。生产校验器复核仍因 MIME 不一致拒绝。文件来源/浏览器为何标错类型未确定。
- 第二张截图 mediaId `01a0bdfc-1810-73de-bed9-301ff9838203` 于 2026-09-20 16:43:37 处理失败，数据库失败码为 MEDIA_VIDEO_DURATION_EXCEEDED。只读 ffprobe 测得 13.903333 秒，含 H.264 视频及 AAC 音轨，上传大小/摘要一致。前端原来以 MEDIA_FAILURE_NOT_RETRYABLE 包装失败，隐藏时长原因。

## 改动

- 新拍摄图片按内容头识别 JPEG/PNG，修正错误 MIME；JPEG 继续使用既有 EXIF 白名单处理。
- 对尚未成功上传、没有待续传上传事务的旧草稿，在重试上传前校正格式、重新计算摘要并保存检查点。正在续传和已成功验证材料继续遵循原恢复流程。
- 媒体错误取消通用“修正标记的字段”提示；后台失败原因通过允许列表显示，不透传内部错误。
- 时长失败说明视频须为 1–10 秒并保留声音；凭证卡标记“校验失败”，视频预览显示具体原因，可删除后重新拍摄。
- 已确认处理失败的素材持久化失败状态，重复点击不再重复上传同一文件；只有学生主动删除本机失败素材并拍摄替代材料后才继续。
