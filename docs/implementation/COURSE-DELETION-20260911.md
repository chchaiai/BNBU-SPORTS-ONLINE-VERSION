# 教师课程彻底删除与无班级进班验收

## 已确认业务范围
责任教师删除本人课程，二次确认填写完整课程名称、原因并勾选影响确认。课程、成员关系及该课程打卡、审核、学时、照片视频和关联申请/结算等数据被删除。学生账号、邮箱绑定和其他课程数据保留；已关闭课程也可删除。删除审计与幂等回执保留。

## 根因与修复
旧关闭操作只结束成员关系，保留课程及历史记录。新增 POST /class-sections/{id}/delete，教师网页用彻底删除替代关闭入口；验证任课教师、NORMAL 模式、版本、课程名称、明确确认。数据库 0062 安装课程范围的原子删除函数，复用经过限定的逐行删除计划与媒体清理队列；未知外键依赖或跨课程关系整批失败回滚。迁移本身不执行业务数据删除，插入历史保护继续保留。
学生端复用已有首页/课程扫码和邀请码入口，修正无有效班级时遗留 ACTIVE 入班请求阻挡新进班的问题，并修复打卡空状态两个按钮原先绑定空操作的问题。
