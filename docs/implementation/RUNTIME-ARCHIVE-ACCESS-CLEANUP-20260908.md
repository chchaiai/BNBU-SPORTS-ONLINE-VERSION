# 归档下载权限、过期与清理 Docker E2E（2026-09-08）

统一归档HTTP链路启用现有访问探针：超级管理员下载后，通过明确数据库夹具改为无权限分管理员，同一下载URL立即403；赋予AUDIT_QUERY后200。人工推进下载凭据的过期时间，旧URL404；重新签发凭据可下载。用户账号、组织和会话仍使用真实权限检查。

取消后调用真实worker.cleanup两次，对象存储中的派生ZIP删除、持久清理记录和事件各1条；事件关联archiveId/jobVersion。归档任务标识、状态、版本和存储引用保留，原始日志字节不变。后台自动清理可能已先完成，重复调用仍应安全。对象存储为MemoryObjectStorage，因此只证明适配器调用与业务清理闭环，不证明COS物理清理。

Docker专用PostgreSQL、Nest HTTP和严格协议，整条归档套件1/1通过，日志docker-runtime-archive-access-cleanup-first-20260908.txt。未修改产品代码或UI。时间过期和权限切换为明确夹具，尚未验证真实等待过期或管理页面点击变更权限；实际权限变更API另有统一分管理员测试。整体目标继续。
