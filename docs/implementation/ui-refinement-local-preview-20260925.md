# UI 本地预览第一版

日期：2026-09-25。基础提交：`0f52b5ed`。范围：学生 Web、教师和管理员门户的界面呈现。仅本地修改及预览。

## 本版调整

- 统一正文、说明、标题、按钮、表格和卡片的视觉规格，改善小字与按钮对比度。
- 教师课程卡片使用两列操作区；手机学生名单改为逐人排列，筛选可以展开和收起。
- 教师审核页面压缩顶部信息；公共审核说明可以展开；保留逐条审核结果与必要说明。
- 修复教师反馈页深色主题，补充反馈及相关界面的英文文案。
- 管理员账号页保留三项常用筛选，其他条件放入“更多筛选”；默认七列，支持切换全部十五列。
- 管理员弹窗及抽屉通过全局浮层显示，修复侧栏遮挡，加入初始焦点、Tab 循环与关闭后焦点恢复。
- 学期状态采用中文标签，申请时间使用格式化日期，诊断信息可以展开。
- 学生首页分开显示完成分钟、目标和百分比；进行中的运动使用一个主要入口；无补证待办时简化展示。
- 学生课程去除重复学期，修复详情分隔线；申请须知可以展开，类型选项统一排列，等待审核使用信息提示。
- 浮动底栏加入安全区间距并调整标签与阴影。

## 课程设置预览补全

用户发现“课程管理 → 进入课程”缺少多项功能。对比 `0f52b5ed` 与第一版 UI 提交 `9d2721bb`，这些入口的隐藏条件原已存在：名称、历史补卡、结算、删除课程及四项运动规则仅在真实模式显示；演示模式也没有加载模板和总目标。

- 为既有四个课程组件提供显式本地预览参数，复用原有表单、名单、结算和删除确认界面。
- 各预览读取、保存、导出和删除处理在调用 API 或写入真实请求恢复记录前返回。反馈明确标注本地预览；删除确认不删除课程，导出仅提示正式文件需登录。
- 填入示例模板、总目标、单次最长与最短时长、每周与每日次数；课程名称和规则调整在当前页面内保留，刷新恢复示例。
- 修复课程弹窗 Grid 内容撑宽的问题；390px 宽度下完整显示两列统计卡，结算表格在自己的容器内横向滚动。
- 验证：完整类型检查、构建通过；课程名称映射、发布意图、课程翻译、已删除课程过滤及翻译资源相关测试共 8 项通过。
- 浏览器验证：新增入口及示例值、改名、补卡保存反馈、结算报告示例、删除确认、规则保存后重开保留数值；桌面与 390px 手机宽度检查通过，控制台无错误。

仅为本地合成数据的界面预览验收，未验证真实课程的后端保存、结算或文件导出。
