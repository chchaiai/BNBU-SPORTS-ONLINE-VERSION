# 教师端与管理端手机适配（2026-09-20）

## 修改

- 860px 及以下使用紧凑的菜单栏。展开后以两列显示所有导航和个人信息入口；选页、打开个人信息、Escape 均可关闭，焦点回到菜单按钮。
- 手机菜单不受桌面侧栏已折叠状态影响；桌面仍使用原侧栏。
- 顶部标题、学期、语言和主题控件自动换行；内容留出安全区，表单文字避免移动端输入放大。
- 统一表格容器的水平滚动、筛选栏宽度、状态标签滚动和课程卡片文字换行，修复真实长课程名造成的整页溢出。
- 弹窗使用动态视口高度，内容区独立滚动，底部操作按钮可见。修复页面切换动画使固定弹窗相对页面定位、被手机导航覆盖的问题。
- 样式集中于 mobile-workspace.css，使用现有颜色变量与组件；无需后端业务修改或数据迁移。

## 验证

- 本地合成预览：教师 6 页、管理员 11 页，在 320、390、768、1280px 下共 68 次页面检查，整页无横向溢出；浏览器 pageerror 为零。
- 菜单开关、Escape、切换后收起、个人信息弹窗，以及桌面折叠侧栏后切到手机均通过。
- 教师新建课程、管理员新增分管理员弹窗，在 390×700 与 390×480 下共 4 项验证通过；标题未被菜单覆盖，底部按钮在视口内，正文可滚动。
- 真实本地 HTTP/PostgreSQL：教师和管理员真实认证、首页布局、导航与个人信息弹窗通过；同文件的 4 项既有 HTTP 测试通过，共 5 项通过。无生产业务写入。
- 完整前端 typecheck、构建通过。既有静态测试 28/29 通过；未通过项要求原生 select 数量为 2，但未改动的 HEAD 已有 4 个。
- 原始 lint 的通知轮询 effect 既有错误保留；排除该既有规则后，本次修改文件检查通过，仅保留已有 img 警告。完整 lint 不记为通过。
- 验证为 Edge 浏览器视口模拟及本地真实服务，未声称实体 iPhone/Android 测试。
