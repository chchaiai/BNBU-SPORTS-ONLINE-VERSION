# 维护模式网页接线与恢复 2026-09-09

## 现有页面接线

AdminSystem 原真实模式只查询且禁用已有按钮。现已沿用原模式按钮、公告弹窗、表单和页面结构，POST /system-mode/changes 提交当前策略版本、原因及双语公告；预计恢复时间转换 ISO UTC。预计恢复时间只作提示，恢复需管理员实际切换。移除旧只读/未开放文案，未修改 CSS、尺寸或版式。

请求开始后锁定原表单和取消操作；响应丢失保留原 body/key，原按钮重试。成功采用服务器策略版本并关闭弹窗。明确验证/权限/冲突失败可重新编辑，网络或未知结果保持原请求。本轮没有实现刷新或重新登录后的未确认请求恢复；维护历史页面仍仅本地预览，后端历史已存在。

1. 初次浏览器真实切换后公开模式返回 503，登录也受阻：本地两个合成学校模式不一致，公开入口没有学校范围。增加可选 PUBLIC_ORGANIZATION_CODE，严格非空格式/32 字符验证，按数据库既有 organization_code 选择公开状态及公告；未知学校 fail closed。未配置时保留原一致性检查。浏览器专用环境设 BNBU，部署示例说明需配置真实既有学校代码，未修改腾讯云环境。
2. 首次构建遇到 exactOptionalPropertyTypes 可选配置赋 undefined 类型错误，修正类型；原失败 docker-system-mode-scoped-20260909.txt 保留，复测文件 6/6。
3. 管理员刷新会话 GET /me 在维护中被阻止。SystemModeGuard 仅允许已认证 ADMIN 读取自己的身份，以恢复管理会话；教师读取仍 503。原会话认证、角色和权限检查继续执行。
4. 管理员工作台全局加载普通换算表等业务请求，维护中失败挡住系统恢复页。真实系统模式页独立于普通业务预加载的成败，使用自身状态查询。
5. 完整第十七轮 95/96，唯一失败为教师维护中 GET /me 503 未在协议声明；补充 ServiceUnavailable 和生成结果，未改错误业务行为。原全量日志及协议报告保留，后续全量结果另记。
