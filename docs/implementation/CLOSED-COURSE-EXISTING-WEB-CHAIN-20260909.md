# 课程关闭前合法运动的网页收尾

2026-09-09，现有 Docker 后端、PostgreSQL v81_browser_test、MinIO 和 Mailpit。新建独立合成教学班和学生，复用原联调组织的已发布规则来源，责任教师开启人工审核。没有关闭其他已有课程，没有删除失败历史。账号/标识仅保留在忽略目录 closed-course-browser.json。

实际网页流程：学生邮件 OTP 登录并在开放课程开始运动 → 教师在原课程设置弹窗关闭课程 → 学生刷新后拍摄、暂停/恢复、结束相同服务器会话 → 私有图片上传及首次材料提交 → 教师在关闭课程退回一次补证 → 学生拍摄并提交补证 → 教师最终通过 → 学生记录页回读“有效 · 未计入”。新运动请求在合法输入下返回 409。首次/补充材料版本均保留，supplementUsed=true。

运动实际经过服务器计时 8 秒；相机为浏览器合成设备，图片由真实上传链路存入本地 MinIO。这个测试证明关闭后的业务连续性和零计入结果，不证明正向学时达标、真实运动真实性或云端服务。

首次脚本在补证按钮等待超时：学生仍显示提交成功回执，需要点击“查看打卡记录”完成原页面下一步。截图确认原因，产品无需修改。脚本增加正常可见导航步骤；同时核对接口 DTO 后给“关闭后新运动拒绝”请求补足必填 clientObservedAt，避免把参数 422 误当课程关闭拒绝。原脚本编辑曾有 PowerShell 字符串解析失败，未写入文件，改用补丁编辑。
