# 教师自选课程参数与新学生入班

用户已授权在原课程设置弹窗内显示两类目标，并增加运动门槛和每周次数两个选择框。本次沿用原弹窗、区块和 CSS，不调整页面骨架或侧栏。

## 实现

- 显示原课程相关/自主运动目标输入；总和仍校验为 20 小时。
- 门槛与周次数选项读取已发布模板，支持现行 30/45/60 分钟和 2/3/4 次。提交教师选择，纳入原发布请求的内容指纹，避免未确认重试时混用不同参数。
- 发布后重新读取后端两类目标、门槛和周次数，禁用四项输入；加载未完成时也禁用，避免晚到回读覆盖编辑。
- 不修改协议、数据库或后端业务规则。
