# 系统操作审计来源交接

本次完成 V8.1 自动任务的明确来源写入。整体三端业务验收仍未完成。

## 实现与边界

- 0051 迁移新增明确的系统来源标志、实际执行结果和安全原因代码。系统事件必须没有用户操作人，并保存 `SYSTEM` 角色；数据库拒绝同时写入系统标志和教师/管理员用户 ID。
- OCR 请求排队继续记录发起教师，任务记录保留该教师的请求关联。后台领取和识别结果改为系统主体，执行超时记录 `FAILED / OCR_PROVIDER_TIMEOUT`；任务领取成功只表示领取动作完成，不表示识别成功。
- 补证自动逾期、课程提醒、运行归档后台生成及派生文件清理通过共用写入函数明确记录系统主体。补证逾期动作成功和学生记录无效分别表达，不能把业务无效误写成系统执行失败。
- 审计列表、详情、结果筛选和服务器 ZIP 使用已存储字段。没有存储的历史结果/原因仍为 NULL，不按事件名称猜测；旧事件不回填、不改写，历史中已存在的来源缺失或错误归属仍保留。
- 本地 Draft 仍为 229 个操作，补充 `actorRoleSnapshot=SYSTEM` 的字段说明。普通审计只输出版本安全元数据，内部 facts 不外发。本轮未修改前端或业务权威文档。
