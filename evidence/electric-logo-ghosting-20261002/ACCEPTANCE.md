# 标志重影修复 · 2026-10-02

原因：静态图按完整图片及 CSS padding 进行 object-fit: contain；ElectricLogo 按裁剪后的非透明边界另行居中并缩放到 88%。两层尺寸和原点不同，叠加后出现重影，SPORTS 字样尤为明显。

修复：轮廓保留原始画布尺寸与裁剪偏移，发光层使用与静态图相同的 contain 坐标、padding 和居中方式。保留现有电光、交互及静态回退表现。

验证：9 项测试通过，包括不对称留白、四种图标尺寸、裁剪边界变化、异步加载和减少动态效果。浏览器中 APP 入口、首页及个人中心均正常加载，每处只有一个画布，页面切换后正常，无控制台错误或警告。修复后的截图见 after.png 和 detail.png。
