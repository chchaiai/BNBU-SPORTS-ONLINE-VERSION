# BNBU SPORTS 电光标志 · 本地预览

依据用户上传的 React Bits ElectricLogo 代码及后续澄清：使用完整 BNBU 图形与 SPORTS 字样，共同参与发光描边。最终素材来自学生端已有完整标志的透明遮罩；用户上传的金属图片保存为参考，没有作为黑底图片块放入页面。

修改位置：底部首页图标、APP 推广入口、个人中心身份卡。APP 内测提示中的标志同步使用同一组件。打卡、凭证上传队列和其他页面布局沿用原实现。

## 实现

- 保留用户提供的 ElectricLogo 轮廓计算及 WebGL shader，适配现有原生 JavaScript 页面，使用本地固定 OGL 1.0.11，附带两份许可证。
- 银灰透明静态标志即时可见；加载完成后，图形与 SPORTS 字母一起呈现电光描边。浅色背景用蓝色轮廓，蓝色入口使用白色电光。
- 缓存 240px 轮廓；每个标志最多一个画布，限制到 30fps；可见性改变时暂停、移除节点时释放。重绘时保留同一标志节点，交互监听仍指向当前按钮。
- 默认跟随系统减少动态效果；资源失败保留静态标志。仅本地连续预览支持 `?logoMotion=full` / `?logoMotion=reduced`，不注入运动阶段或更改计时。
